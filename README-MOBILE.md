# Counter Picker on your phone

Use this private GitHub Codespace to open the packaged Counter Picker in your
phone's browser. You do not need to download the ZIP, install Python, or type
commands.

1. Sign in to the GitHub account that can access this private repository.
2. Open [Start or resume Counter Picker](https://codespaces.new/marvelagent210-sys/leagueoflegendscounterpicker/tree/counter-picker-download-b1311dfa?quickstart=1).
3. If asked, select **Create codespace**. Allow the first setup to finish.
4. The Counter Picker preview should open automatically. If your browser blocks
   it, open the Codespace's **Ports** tab and select **Open in Browser** for port
   **8000**, labelled **Counter Picker**.
5. Keep that port's visibility **Private**. GitHub requires your sign-in to access
   it. Bookmark the preview URL to return to the app while the Codespace is running.

When a Codespace is stopped or automatically sleeps, its preview is unavailable.
Use the start/resume link above and let startup finish to open it again.
GitHub's default idle timeout is 30 minutes. The Codespace may sleep even while
the app is open because this server runs in the background. This is a private
development preview rather than permanent hosting.

GitHub Codespaces uses your account's compute and storage quota. GitHub Free
personal accounts include 120 core-hours and 15 GB-month of storage per month.
A 2-core Codespace uses two core-hours per running hour. Stop it when finished;
delete it when no longer needed to stop storage usage. Usage beyond your account's
included quota may be billed if you have enabled paid usage.

This preview serves the current packaged build (dataset 16.20, 49 simulator kits).
The startup checks the archive checksum and dataset fingerprint before serving it.
See **ACCURACY.md** inside the ZIP for the simulation's limits.
