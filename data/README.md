# Data

Generated by `npm run build:data`; don't edit these files by hand. `raw/` holds the downloaded sources and isn't committed. Each patch folder has `champions.json` (base stats), `abilities/` (one JSON file per champion), `kits/` (readable pages for checking), `oracle/` (the wiki's level-20 table used by the tests) and `reports/`.
