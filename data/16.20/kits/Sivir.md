If the triggering attack critically strikes, the bounces will do so as well for 200% damage. Ricochet deals 65% damage against minions and executes them if they would be left below 15 health.

Bounces occur only up to 8 times and can target each enemy up to one additional time per empowered attack. They prioritize the nearest new target, then the nearest target if no new targets are available.

Ricochet resets Sivir's basic attack timer if it was not already active. The target does not have to be visible to be bounced to.

- **Mechanics:** attack reset; reveal
